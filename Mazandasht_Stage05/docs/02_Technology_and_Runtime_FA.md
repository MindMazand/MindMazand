# فناوری و اجرای برنامه

## تصمیم مرحله دوم
- رابط دسکتاپ: WPF
- Runtime: .NET Framework 4.8
- دیتابیس: SQLite محلی
- Provider پیشنهادی برای آزمون اولیه: `System.Data.SQLite.Core 1.0.119`
- خواندن Excel: `ExcelDataReader 3.9.0`
- ذخیره رمز عبور: PBKDF2-HMAC-SHA256 با ۶۰۰٬۰۰۰ تکرار و Salt مستقل
- کلید کاربر: ۳۲ بایت تصادفی؛ فقط SHA-256 آن در دیتابیس ذخیره می‌شود؛ Secret خام فقط یک‌بار به UI بازگردانده می‌شود.

## محل دیتابیس در پوسته فعلی
`%LOCALAPPDATA%\Mazandasht\Data\mazandasht.db`

این مسیر برای چند کاربر نرم‌افزاری که با یک پروفایل ویندوز وارد می‌شوند مشترک است. اگر چند پروفایل ویندوز مستقل قرار است از یک دیتابیس مشترک استفاده کنند، پیش از تولید نصب‌کننده باید مسیر مشترک ProgramData و ACL محدودشده طراحی و آزمون شود.

## PRAGMAهای دیتابیس
- `foreign_keys=ON`
- `journal_mode=WAL`
- `synchronous=FULL`
- `busy_timeout=5000`

## نکته سازگاری
Windows 8.1 آخرین نسخه‌های .NET جدید را پشتیبانی نمی‌کند. .NET Framework 4.8 در فهرست سازگاری تاریخی Windows 8.1 Update قرار دارد، اما خود Windows 8.1 خارج از پشتیبانی امنیتی است. این نسخه هدف، صرفاً برای الزام سازگاری قدیمی نگه داشته شده و باید روی دستگاه واقعی آزمون شود.
