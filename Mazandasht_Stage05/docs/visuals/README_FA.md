# طرح‌های مفهومی رابط کاربری مازندشت

این پوشه طرح‌های مفهومی و نمونه‌های هنری رابط کاربری را نگه می‌دارد. هیچ‌کدام اسکرین‌شات
نرم‌افزار اجراشده نیستند و اعداد داخل آن‌ها نمونه گرافیکی‌اند؛ نباید به‌عنوان داده واقعی
یا گزارش سیستم تلقی شوند.

| فایل | توضیح |
| --- | --- |
| `dashboard-concept-not-runtime.png` | طرح مفهومی اولیه داشبورد (مرحله ۵ اول). |
| `ui-mockup-light.svg` | طرح داشبورد مدیریتی با تم روشن (ویندوز). |
| `ui-mockup-dark.svg` | طرح داشبورد مدیریتی با تم تیره. |
| `ui-design-system-light.svg` | کتابخانه اجزا: رنگ‌ها، دکمه‌ها، فیلدها، برچسب‌ها و جدول (تم روشن). |
| `ui-design-system-dark.svg` | همان کتابخانه اجزا با تم تیره. |

همهٔ فایل‌های SVG با ابزار `tools/build_mockups.py` ساخته می‌شوند و متن فارسی آن‌ها متن
واقعی است (نه تصویر)، بنابراین در مرورگر با فونت وزیرمتن درست نمایش داده می‌شوند.

## تم‌ها

چهار تم در نرم‌افزار تعبیه شده است: «ویندوز» (روشن، پیش‌فرض)، «تیره»، «کاسپین» و «جنگل».
تعریف هر تم در `app/Mazandasht.Desktop/Assets/Themes/Theme.<نام>.xaml` است و با
`tools/build_themes.py` از یک منبع واحد تولید می‌شود.
