# معیار پذیرش سخت‌گیرانه مرحله چهارم

| محور | معیار پذیرش |
|---|---|
| اشخاص | ایجاد اتمیک Party + Ledger Account + Party Account؛ کد یکتا؛ اطلاعات حساس DPAPI؛ HMAC برای تطبیق کد ملی؛ Audit Log |
| محصولات | کد یکتا، گروه مرجع، واحد؛ جلوگیری از محصول فعال تکراری در یک گروه |
| فهرست‌ها | انتخاب از DB، جست‌وجوی نام/کد و ایجاد سریع با +؛ عدم پذیرش مقدار آزاد ناشناخته |
| باسکول | اعتبارسنجی جهت، طرف حساب، محصول، انبار، وزن، تعداد بسته، تار و افت؛ ذخیره وزن به گرم |
| موجودی | FIFO در خروج؛ Pending تا تأیید؛ Trigger جلوگیری از موجودی منفی؛ تراکنش اتمیک |
| تأیید | فقط ADMIN/MANAGER؛ ثبت تأییدکننده، زمان و تاریخچه؛ جلوگیری از انتقال وضعیت نامعتبر |
| داشبورد | فقط سند قطعی؛ مبالغ ریال/تومان صرفاً در نمایش؛ نمودار واقعی هفت‌روزه |

## موارد خارج از ادعای تکمیل
- Build واقعی WPF و نصب‌کننده روی Windows 8.1/10/11 در این محیط انجام نشده است.
- ورود INFO و سایر فایل‌های واقعی به دیتابیس عملیاتی انجام نشده؛ فقط پیش‌نمایش و قواعد مهاجرت تولید شده‌اند.
- ماژول‌های خرید، فروش، سورتینگ، پرداخت و چک هنوز در این مرحله تکمیل نشده‌اند.
- پنجره دوم مانیتور و پشتیبان‌گیری خودکار هنوز در این بسته عملیاتی نیستند.
