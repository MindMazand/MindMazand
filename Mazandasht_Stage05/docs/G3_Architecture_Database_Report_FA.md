## ۲. migration_006 (نسخه ساختار ۶)

فایل: `app/Mazandasht.Desktop/Database/migration_006.sql`

| بخش | محتوا |
|---|---|
| ۱ | **کارخانه حسابداری پیش‌فرض** — ۱۶ حساب سیستمی در ۵ کلاس (دارایی، بدهی، سرمایه، درآمد، هزینه) |
| ۲ | **تخصیص تسویه** — جدول `settlement_allocations` + ترگر منع بیش‌تخصیص و ترگر الزام به وجود سند پرداخت |
| ۳ | **نماهای گزارشی** — `v_stock_on_hand`، `v_party_balance`، `v_basket_custody_balance`، `v_bank_balance`، `v_cheque_register`، `v_profit_loss` |
| ۴ | **ترگرهای یکپارچگی** — وزن خالص باسکول، قیمت ردیف خرید/فروش (گردکردن half-up)، تسویه‌ای سورتینگ، مبلغ وصول چک، شماره‌گذاری خودکار سند |
| ۵ | **مجوز `database.reset`** فقط برای ADMIN |
| ۶ | ثبت نسخه و `PRAGMA user_version = 6` |

### ترگرهای کلیدی و شواهد اجرا

| ترگر | قاعده | تست |
|---|---|---|
| `trg_weighing_net_weight_check` | `net = gross − tare − loss` | رد ناسازگار، پذیرش سازگار |
| `trg_purchase_line_amount_check` | `net = round_half_up(qty×price/1000) − discount + freight + commission + other` | ۱گرم×۱۵۰۰ = ۲ (half-up) |
| `trg_sales_line_amount_check` | معادل فروش | رد ناسازگار |
| `trg_sorting_recompute_*` | `variance = input − output − waste − loss` و وضعیت MATCHED/WARNING | خودکار محاسبه می‌شود |
| `trg_cheque_clearance_amount_check` | وصول چک باید مبلغ کامل باشد | رد مبلغ ناقص |
| `trg_settlement_not_exceed_payment` | Σ تخصیص ≤ مبلغ پرداخت | رد بیش‌تخصیص |
| `trg_document_number_autofill` | شماره تخصیص یافته از `document_sequences` | ۱، ۲ و یکتا |
