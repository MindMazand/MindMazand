# مازندشت — مرحله پنجم، بازنگری ۰.۵.۱

## این بسته چه چیزی دارد؟

- سورس WPF مبتنی بر .NET Framework 4.8 و SQLite محلی.
- مهاجرت افزایشی دیتابیس از نسخه ۴ به نسخه ۵؛ داده‌های موجود در به‌روزرسانی عادی پاک نمی‌شوند.
- فهرست ۱۲ نام نمونه بانک در `bank_catalog`؛ بدون ایجاد حساب واقعی، شماره حساب، شبا، صاحب حساب یا مانده.
- گروه‌ها و انواع عملیات پیش‌فرض قابل مشاهده در تنظیمات؛ مدیر مجاز می‌تواند عملیات جدید با ماهیت ورودی، خروجی یا خنثی تعریف کند.
- پنجره اطلاعات پایه با تب‌های فهرست بانک‌ها و انواع عملیات.
- دکمه مدیریت دیتابیس فقط برای نقش `ADMIN` نمایش داده می‌شود و سرویس پاکسازی نیز مجدداً مدیر فعال را کنترل می‌کند.
- پیشنهاد اختیاری و یک‌باره برای بازکردن مرکز ورود اطلاعات پس از نخستین ورود مدیر به دیتابیس تمیز.
- ورودی فایل‌های `.xlsx`, `.xls`, `.csv` با محدودیت حجم، ردیف و ستون، پیش‌نمایش و نگاشت.
- ۱۱ قالب Excel خالی و مستندات راه‌اندازی.

## مرزهای داده

در دیتابیس اولیه هیچ شخص، محصول واقعی، حساب بانکی، موجودی، فاکتور، تراکنش، چک یا مانده‌ای وجود ندارد. فقط داده‌های سیستمی و کاتالوگ‌های نمونه قابل مشاهده هستند.

## ورود اطلاعات

مرکز ورود فایل را پیش‌نمایش و نگاشت می‌کند. ذخیره در صف بررسی رمزگذاری‌شده است و به‌معنای Commit عملیاتی نیست. انتقال نهایی هر پروفایل به جداول عملیاتی باید با Writer تراکنشی و آزمون‌های اختصاصی همان ماژول تکمیل شود. این محدودیت در UI و مستندات پنهان نشده است.

## پاکسازی

فقط ADMIN می‌تواند پاکسازی را اجرا کند. قبل از جایگزینی، Backup مستقل SQLite و گزارش SHA-256 ساخته می‌شود. دیتابیس جدید با schema، نقش‌ها/مجوزها، واحدها، گروه‌ها، عملیات پیش‌فرض و نام بانک‌های نمونه ساخته می‌شود؛ همه کاربران و داده‌های تجاری حذف می‌شوند و مدیر اولیه باید دوباره ایجاد شود.

## اجرای تست‌ها

```bash
python -m pytest -q
```

آخرین اجرای قابل انجام در محیط توسعه: ۱۷ تست موفق، ۱ تست Skip. تست Skip به‌دلیل وابستگی به محیط/داده‌ای که در این اجرای مستقل موجود نبود.

## Build ویندوز

پیش‌نیاز: Windows 8.1 Update یا جدیدتر، .NET Framework 4.8 Developer Pack و Visual Studio/MSBuild با ابزار WPF.

```bat
msbuild app\Mazandasht.sln /restore /p:Configuration=Release /p:Platform="Any CPU"
```

Build واقعی WPF در محیط فعلی انجام نشده است؛ در این بسته ادعای ساخت EXE یا نصب‌کننده نهایی وجود ندارد.
